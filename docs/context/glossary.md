# Glossário

| Termo | Definição no projeto |
|---|---|
| Base | Local seguro que o jogador mantém e aprimora para sobreviver. |
| Farol | Estrutura inacabada na ilha; seu aprimoramento e conclusão são objetivos centrais. |
| Noite | Período de risco elevado, com animais selvagens progressivamente mais perigosos. |
